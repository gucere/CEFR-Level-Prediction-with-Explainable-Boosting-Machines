_**Purpose of this Folder**_

&nbsp;&nbsp;&nbsp;&nbsp;This folder contains an automation system for running TAALES 2.2 reliably. It automatically handles freezes, runtime errors, crashes, partial results, restarts, failed-file retries, and temporary-file cleanup.

_**Requirements**_

&nbsp;&nbsp;&nbsp;&nbsp;- Windows 10 or Windows 11  

&nbsp;&nbsp;&nbsp;&nbsp;- TAALES 2.2 for Windows  

&nbsp;&nbsp;&nbsp;&nbsp;- Python 3.10 or later  

&nbsp;&nbsp;&nbsp;&nbsp;- An active and unlocked Windows desktop session  

_**How to Run TAALES With This Automation**_

&nbsp;&nbsp;&nbsp;&nbsp; Open up powershell in this folder and execute following 2 lines:

&nbsp;&nbsp;&nbsp;&nbsp; Set-ExecutionPolicy -Scope Process Bypass

&nbsp;&nbsp;&nbsp;&nbsp; & ".\Start-TAALES-Automation.ps1"

_**How to Find TAALES Online**_

&nbsp;&nbsp;&nbsp;&nbsp;- [TAALES Link](https://www.linguisticanalysistools.org/taales.html)
